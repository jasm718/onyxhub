# onyxhub 应用虚拟化平台

一个远程应用虚拟化平台，管理分发运行于本机上的windows remoteapp应用。

# 系统构成

## 管理端

管理端实际由2部分组成：

- backend & frontend: 管理后台，供管理员登录并管理整个系统
- agent: agent控制服务，负责上报本机信息，发布应用，启动应用，以及一切跟远程应用主机调度相关的工作
- 这2部分是分开的2个进程，通过端口相互通信，这样的设计能够保证以后方便扩展到多agent端的架构

### 管理后台

管理员可以在管理平台上管理用户、发布应用、设置连接策略等，页面包括了：

- 首页仪表盘
- 远程应用
- 用户管理
- 连接策略
- 设置
  - 通用设置
  - 存储设置
  - 安全设置
  - 授权

### agent控制服务

agent主要用于接受管理端指令，控制主机系统以及主动处理一些跟主机系统相关的工作：

- 发送主机系统信息到服务端（CPU、内存、显卡、存储）
- 管理主机系统用户
- 启动、关闭用户连接
- 其他主机系统控制功能

## 客户端 client

用户使用的客户端，可以让用户登录，登录成功显示已授权的应用，用户点击已授权应用即可使用启动器去启动远程连接
